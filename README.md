# Student Daily Expense Tracker

## 📖 About This Project
This is a simple program designed to help students track their daily expenses and manage their weekly budget. The goal is to encourage better money management habits through a straightforward, easy-to-use tool.

## 🎯 Purpose
Many students struggle to keep track of their spending. This project provides a simple solution that helps users record expenses, set a budget limit, and see a summary of where their money goes.

## ✨ Key Features
- Record daily expenses with descriptions
- Set a weekly budget limit
- Real-time total and remaining budget display
- Budget alerts and warnings
- Weekly spending summary

## 📂 Project Status
This repository contains the *initial project proposal only*. The program has not been coded yet — this serves as the planning document.
